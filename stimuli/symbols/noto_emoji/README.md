# Noto Emoji glyphs

Source images for every `stimuli/symbols/buy_<object>/emoji.png`, which
`stimuli/symbols/draw_symbols.py` assembles from them.

Each file is named after its emoji's code point.

Copied unchanged from `2D/png/128/` of
[googlefonts/noto-emoji](https://github.com/googlefonts/noto-emoji) at commit
`99701e07d3d1fe1bdbcdb14964547f0fd592966f`. Copyright Google LLC.
